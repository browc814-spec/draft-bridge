Draft Bridge

CFB 26 → Madden 26 · Dynasty → Franchise draft class helper
Field order is a best guess until it's confirmed against your Madden 26 Edit Draft Class screen. It's set in CARD_ORDER at the top of the script.
Conversion strength
How hard to cut CFB numbers down to Madden rookie level. Athletic ratings stay near the CFB value, while skill and mental ratings (AWR/PRC) drop more. Each player's projected round adds or subtracts a few points.
LightHeavy
Community estimate, not EA's formula. EA hasn't published how CFB ratings translate to Madden. Adjust it to taste, or tap any converted number to override it.
Fate presets (house rules)
How strong ⭐ Star, 💥 Bust, and 💎 Steal are. Points apply to the player's key position ratings and AWR.
Top-N per position
How many prospects you aim to copy at each position (3–5).
Backup & export
Everything saves automatically on this phone. Make a backup now and then, because clearing your browser data wipes it.
Why this exists
CFB 26 can't export Dynasty draft classes to Madden 26. Only a Road to Glory player transfers, and only into Superstar mode. So you rebuild your guys by editing Madden's generated prospects, and this page makes that faster.
Workflow
  1. CFB 26: when players declare, open each top prospect's player card and enter his bio and ratings here (Board → + Add prospect).
  2. Set a projected round, then check the converted Madden numbers. Tap any number to override it.
  3. Madden 26 (PS5): Franchise → get past preseason → Scouting → Prospects → press L3 → Edit Draft Class.
  4. Pick a generated prospect at the same position, open Card mode here, and work down the list, tapping each field once you've set it. Then tap Next player.
  5. To start Year 1 with a downloaded class instead, use Franchise Home → Choose Draft Class → Import Local File.
⚠ Generic-appearance bug
In Madden 26, edited faces, skin tone, and gear can look right in the editor but show up as a generic player in games. The community workaround: upload your class to Madden Share, then load it from Prospects → L3 → Download from Download Center, not Import Local File.
Ratings use CFB 26's abbreviations (SPD, THP, SAC, MAC, DAC, PRC, MCV, ZCV, and so on). Madden uses the same rating families, but confirm names on your screen. Madden 26 positions (LEDG/REDG edges, SAM/MIKE/WILL linebackers) follow EA's Madden 26 notes. The long snapper (LS) is left out for now.
